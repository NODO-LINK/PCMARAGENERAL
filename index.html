Operaciones de Emergencia

Lista Diaria de Pacientes Atendidos

Una planilla por día: escriba las cantidades totales atendidas y el responsable del día.

Importar pacientes desde Excel/CSV

El archivo debe traer una fila por paciente (con columnas como Fecha ingreso, Nombre, Cédula, Edad, Sexo, etc.). Como la planilla diaria solo guarda totales por día, el sistema agrupa automáticamente los pacientes por su Fecha de ingreso y cuenta cuántos son Niños (0-11), Adolescentes (12-17) y Adultos (18+) según la columna Edad — se genera una planilla por cada fecha distinta encontrada. Los demás datos del paciente (nombre, cédula, teléfono, diagnóstico, etc.) no se guardan, solo se usan para contar. Los pacientes sin fecha o sin edad válida no se cuentan (se informa cuántos fueron). Si ya existe una planilla guardada para alguna de esas fechas, se crea una planilla adicional para esa fecha (los totales se suman igual en las estadísticas). Se aceptan CSV separados por coma o por punto y coma.

Imprimir Lista Diaria

Genera el documento formal del día seleccionado con el conteo de niños, adolescentes, adultos, traslados, fallecidos e insumos utilizados — listo para la firma del Jefe de Departamento y el Director.

Importar traslados desde Excel/CSV

El archivo debe tener columnas Fecha (fecha y hora), Tipo (Apoyo o Interhospitalario — "Emergencia" se acepta como sinónimo de Apoyo, y "Traslado programado" como sinónimo de Interhospitalario), Institución (Centro destino), Nombre del paciente y Unidad. Opcionalmente Cédula, Edad, Responsable y Observaciones. Si el texto de Institución coincide con el nombre de una institución del catálogo, el traslado queda vinculado a ella y se cuenta en su estadística; si no coincide, se guarda igual como texto. Si una fila no trae responsable, se usa el indicado abajo. Se aceptan CSV separados por coma o por punto y coma.

Guardias de Prevención

Importar guardias desde Excel/CSV

El archivo debe tener columnas Fecha, Parroquia, Lugar, y Actividad (descripción). Opcionalmente Población (cantidad de personas abarcadas), Responsable y Observaciones. Si una fila no trae responsable, se usa el indicado abajo. Se aceptan CSV separados por coma o por punto y coma.

Despacho de Combustible

Las instituciones se seleccionan del catálogo maestro. Gestione el catálogo desde Catálogos → Instituciones.

Importar despachos desde Excel/CSV

El archivo debe tener columnas Fecha, Institución, Tipo (Gasolina o Diesel — "Diésel" se acepta igual), Litros (cantidad despachada) y Vehículo (unidad/placa). Opcionalmente Responsable y Observaciones. La institución es obligatoria: si el texto no coincide con el catálogo, se debe resolver abajo (crear institución nueva o vincular como alias) antes de poder importar esa fila. Si una fila no trae responsable, se usa el indicado abajo. Se aceptan CSV separados por coma o por punto y coma.

Nuevo insumo

Importar insumos desde Excel/CSV

El archivo debe tener columnas Nombre, Categoría, Existencia (cantidad) y opcionalmente Ubicación/Almacén y Mínimo (nivel crítico). Si no trae Ubicación, se usa el almacén seleccionado abajo para todas las filas. Un mismo insumo puede repetirse una fila por cada almacén (así se cargan las 4 existencias por separado). Si una categoría no existe todavía, se crea automáticamente; si el insumo ya existe, solo se le suma la cantidad como una entrada nueva. Se aceptan CSV separados por coma o por punto y coma.
